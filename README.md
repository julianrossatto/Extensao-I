<h2>Website sobre ORIENTAÇÃO VOCACIONAL <img src="img/funcionarios.png" style="width: 35px"></h2>

Um website desenvolvido como projeto de estudo e extensão universitária em Desenvolvimento Web, utilizando HTML, CSS e JavaScript.

O projeto tem como objetivo auxiliar os usuários na reflexão sobre seus interesses e possibilidades profissionais, por meio de uma interface simples, acolhedora e responsiva, com elementos interativos desenvolvidos em JavaScript.

<h3>Sobre o projeto</h3>

O objetivo do projeto foi desenvolver uma página web estática capaz de apresentar ferramentas e informações relacionadas à orientação vocacional, proporcionando aos usuários um ambiente intuitivo para refletir sobre seus interesses e encontrar possibilidades de carreira.

A interface conta com uma navegação organizada em diferentes seções, além de um formulário interativo destinado à coleta de informações e opiniões dos usuários.

O formulário permite o preenchimento de dados não obrigatórios como nome, idade, profissão, avaliação e comentários. As informações coletadas são encaminhadas para o Google Cloud, utilizando recursos do Google Apps Script e Google Sheets para armazenamento e gerenciamento dos dados.

O projeto foi desenvolvido como parte de uma atividade de extensão universitária, com o propósito de aplicar conhecimentos adquiridos durante a graduação em Engenharia de Software em uma solução web voltada à orientação e reflexão profissional.

O desenvolvimento também foi utilizado para praticar conceitos fundamentais de Desenvolvimento Front-End, como estruturação de páginas com HTML, estilização com CSS, responsividade e manipulação de elementos através do JavaScript.
